AI product development

From product idea to working prototype

I use Claude Code and Replit to move from a product idea to something people can actually use. The tools speed up the building; the product thinking is what decides what gets built and whether it's any good.

  1. 01

    Find the problem worth solving

    Start from user research, feedback and data to name a specific problem and the opportunity behind it, before any tool gets opened.

  2. 02

    Turn a hypothesis into something that runs

    Use Claude Code and Replit to build a working version quickly, so the idea can be tested with real interactions instead of a static mockup.

  3. 03

    Decide what to build, and what not to

    Scope each prototype around the core job, prioritise features by user value, and write down the trade-offs behind each call.

  4. 04

    Test the AI, not just the interface

    Check AI outputs against real inputs, look for the cases where they fail or mislead, and dig into why before trusting the result.

  5. 05

    Improve from evidence

    Feed what testing and feedback show back into the next version, keeping the changes tied to what was actually observed.
